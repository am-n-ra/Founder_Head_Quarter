# Docker — Case Study

## Problem
Solomon Hykes experienced deployment pain daily while building dotCloud (a PaaS). The problem was personal: every customer had different environments, "it works on my machine" was the norm.

## Sacrifice
Dropped out of college to start dotCloud. Then had the courage to abandon dotCloud entirely when Docker took off. Pivoting = sacrificing the existing business.

## Demo
Docker open-sourced at PyCon 2013. Product was initially imperfect: Linux-only, limited networking, immature storage. But it solved the core problem: reproducible environments.

## Distribution
Open: open-source from day one. GitHub stars exploded. Developer community became the distribution channel. No sales team needed.

## Early Believer
The developer community at PyCon 2013. Then Red Hat, Google, and AWS all adopted Docker.

## Incorporation
Trigger-based: initially incorporated as dotCloud (2010). Docker spun out as its own entity later.

## Inflexion
PyCon 2013 demo + GitHub release. The developer community adopted Docker faster than any previous infrastructure tool. Unpredictable: dotCloud was failing, Docker was a side project that saved the company.
